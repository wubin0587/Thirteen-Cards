# 🎴 福建十三水 (Fujian Thirteen Cards) - AI-Powered Card Game

## 📖 项目简介
本项目是一款基于 **Unity** 引擎开发的跨平台棋牌游戏——**福建十三水**（十三张/十三道）。
项目不仅高度还原了经典的本地玩法，还创造性地引入了 **基于 Transformer 架构的深度强化学习 AI**，为玩家提供极具挑战性的人机对战体验与智能化的“一键理牌”辅助。项目计划最终上线应用商店。

---

## ✨ 核心特性

### 🎮 游戏玩法
*   **多人数支持**：支持 3~8 人同局对战。智能适配牌堆：4人及以下使用单副牌（52张），5~8人自动切换为双副牌（104张）。
*   **特色计分机制**：完美实现福建十三水的核心爽点——**“打枪”**（BiuBiu特效）与**“全垒打”**（全屏震撼动效），给予赢家极高的分数翻倍激励。
*   **特殊牌型直接结算**：支持“至尊清龙”、“全大”、“全小”、“三同花顺”等特殊免摆牌型判断。

### 🤖 核心 AI (Transformer + RL)
*   **智能一键理牌**：告别手机端繁琐的拖拽！AI 会瞬间为玩家计算并推荐 3 套最优理牌方案（如：综合最优、冲锋打枪、保底防守），玩家一键即可完成头(3)、中(5)、底(5)的布置。
*   **离线高智商对抗**：模型导出为 `ONNX` 格式，通过 Unity Sentis/Barracuda 嵌入本地客户端，无需联网即可体验零延迟的高难度人机对弈。

### 🌐 联机与多端互通
*   **实时多人服务器对战**：基于 WebSocket 的实时通信，支持好友开房与匹配系统。
*   **严格防作弊**：服务器仅下发玩家自己的手牌，理牌倒计时结束后统一广播结果，从底层杜绝抓包透视。

## 🛠️ 技术架构

### 1. 客户端 (Client)
*   **引擎**：Unity 3D (C#)
*   **UI 系统**：UGUI / UI Toolkit，追求简洁清爽的现代纸牌界面。
*   **本地 AI 推理**：Unity Sentis (原 Barracuda)，直接在手机端高效运行 Transformer 模型。

### 2. 人工智能 (AI Engine)
*   **训练框架**：Python + PyTorch
*   **动作空间掩码 (Action Masking)**：硬性约束算法，过滤“倒水”（头>中 或 中>底）等违规牌型，极大提升训练效率。
*   **自我对弈训练 (Self-Play RL)**：
    1.  让 4 个初始模型在虚拟环境中不断对局。
    2.  设计奖励函数（Reward Function）：胜出/打枪/全垒打获得正反馈，失败/被打枪获得负反馈。
    3.  通过多轮自我博弈与迭代，最终蒸馏出一个参数量轻量、但在有限信息下决策能力极强的 Transformer 模型。

### 3. 服务端 (Backend)
*   **通信协议**：WebSocket (实时出牌/匹配) + HTTP (登录/战绩)
*   **数据存储**：MySQL (用户信息) + Redis (房间状态、实时牌局缓存)
